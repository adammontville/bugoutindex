Methodology — v1.0.0

The BugOut Index aggregates six normalized metrics into a single weighted score on a 0–100 scale, where higher values indicate greater societal stability. This page describes how the current week's number was produced.

2. Normalization

Each metric is normalized to 0–100 using predefined thresholds:

normalized = (1 − (raw − min) / (max − min)) × 100

Trust in Government is inverted (higher trust → higher stability) by applying 100 − normalized after the above transform.

3. Aggregation

The index is the weight-normalized sum of the per-metric scores:

BOI = Σ (normalized_i × weight_i) / Σ weight_i

5. Limitations and caveats

  • Freshness mismatch. Inflation, unemployment, and debt-to-GDP update monthly or quarterly; the Edelman trust score updates annually; homelessness is annual (HUD PIT). The BOI is recomputed weekly but will only move when underlying data publishes.
  • National scope. Crime and homelessness figures are national averages or approximations; local conditions vary substantially.
  • Not a forecast. The BOI describes current observed conditions relative to chosen thresholds, not future outcomes.
  • Threshold sensitivity. Because the index is built on fixed normalization ranges, slow drift inside a range will not move the score — the thresholds are calibrated to reflect historically extreme conditions at the endpoints.

6. Reproducibility

Every weekly run commits the raw inputs, the computed normalized scores, and the final index to this repository. The code that produced this page is open source; you can recompute any historical week by checking out that commit and re-running runtime/publish/weekly_run.py.
