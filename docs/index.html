About this index

The BugOut Index is not a forecast or a prediction. It is a transparent, versioned composite score designed to surface slow-moving shifts in stability that individuals and communities can reason about. All inputs come from public sources; see methodology for the full calculation, weights, and normalization ranges. Historical scores can be recalculated at any time from the raw data in this repository.
