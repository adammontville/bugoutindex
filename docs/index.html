About this index

The BugOut Index is not a forecast or a prediction. It is a transparent, versioned composite score designed to surface slow-moving shifts in stability that individuals and communities can reason about. All inputs come from public sources; see methodology for the full calculation, weights, and normalization ranges. Historical scores can be recalculated at any time from the raw data in this repository.

For the long-horizon structural picture — whether the country is currently set up to produce broadly-shared prosperity and mobility over years and decades — see the American Dream Reality Index (ADRI). ADRI updates annually and weights toward education, health, real income, employment, inequality, and civic and safety fundamentals. The BugOut Index and ADRI are complementary rather than substitutable: BOI moves on short-horizon rupture signals; ADRI moves on slow structural conditions. When BOI spikes, ADRI usually drops as well, but each can move for reasons the other doesn't catch.
